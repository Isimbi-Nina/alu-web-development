# HTML Basic

A small website built with HTML only. It introduces a valid document, a homepage, and a page with an embedded tweet.

## Files

- `base_index.html` — the smallest valid HTML page
- `index.html` — homepage with headings, paragraphs, and a clickable image
- `tweets.html` — a page with one embedded tweet

## Pages

Open `index.html` in a browser. The header links to this homepage and to `tweets.html`.
