Welcome to my first webpage

HTML stands for HyperText Markup Language. It is the language used to describe the structure of a page so a browser can display it.

What is a markup language?

A markup language annotates text with tags. Those tags tell the browser what each part of the document is, such as a heading, a paragraph, or a link.

Elements, tags, and attributes

An element is one part of the page. It is written with a tag, and an attribute adds extra information to that tag, such as the address of a link.

When a browser loads this file, it reads the HTML, builds the Document Object Model (the DOM), and then paints what you see.
